# 动效生产（OpenFilm）

权威规范在 `docs/MOTION.md`。这份技能是入口，读完按它开工，**不要停下来问"要不要继续"**。

## 先判断：这是不是一支片

- 要做/要改/要换风格的**画面** → 走下面的协议。
- 只问问题、只改字幕文字、只换素材音量 → 用 `openfilm-editing`，不要开生产线。

## 七道闸门

| 闸门 | 做什么 | 通过条件 |
|---|---|---|
| G0 接单 | `openfilm_film` 读结构；一句话 brief；自定受众/时长/情绪 | 三个默认值定了 |
| G1 分镜 | 一镜一行：秒 / 画面 / 动作 / 屏上字 | 总时长对得上；一镜一件事 |
| G2 定调帧 | **只写第 1 镜**，`openfilm_frame` 抽 60% 时刻 | 亲眼看过，说得出底色/最大字/重心 |
| G3 量产 | 其余镜头；动作只用 `Motion` 词汇 | 每镜有进出场；无静止 >1.2s |
| G4 声音 | 口播先转写；字幕对齐；音乐避让 | 字幕不折行；音效 ≤6 个 |
| G5 帧检 | 切点前后各 1 帧 + 每镜中点 | 无黑场/静止/闪烁/溢出 |
| G6 交付 | `openfilm_export` → `status` | 回读到路径+分辨率+帧率+时长 |

**G2 不过，不许写 G3。** 风格不对只回 G2，不要从头再来。

## 动作词汇（`assets/motion.js`）

`seg / stagger / cubicOut / quintOut / backOut / spring(t,dur,zeta=.61) / drop / wallScale /
det / halton / jitter / pose / enter / exit / camera / inversePose / reveal / split / unitsIn / count / surface / grain`

原则：**闭式解**（只依赖 t）、**确定性**（禁 `Math.random`/`Date.now`）、**一镜一次重音**。

## 风格与镜头卡

- 风格：`vendor/motion/styles/catalog.json`（14 种，含引擎/色板/bpm/样片）。样片本身就是"给定 t 画一帧"，可以直接改成模板页。
- 镜头卡：`vendor/motion/shotcards/catalog.json`（124 张，10 类）。读 recipe 的**动效核心 + 参数表 + 已知坑**，按自己的时长换算，不要照抄参数。

## 做完的定义

- 成片导出完成，且**回读**过输出（路径、分辨率、帧率、时长）。
- 只允许三种提前停下：无法默认的选择 / 缺资源或权限 / 同一失败重试两次仍不过。
- 其余情况：用默认值继续做完，最后一次性汇报"做了什么、改了什么、哪一镜还可以再改"。

## 红线

静止 >1.2s、全片一种缓动、四向同时飞入、文字越界、连续特效转场、配色超 4 色、
数字直接跳变、音效错位、字幕折行、交付说不出规格——出现任意一条就回炉。

# 动效生产规范（AI 剪辑员工）

> 这份文档是**权威规范**：什么时候该开工、按什么顺序做、做到什么算完、做砸了怎么办。
> 给模型的入口是同名技能 `openfilm-motion`（`skills/openfilm-motion/SKILL.md`），
> 命令与文件格式仍以 `openfilm_guide` 为准。剪辑手法（节奏、字幕、导出档位）见 `openfilm-editing`。

## 0. 它解决的是哪一种失败

以前的失败模式不是"不会剪"，而是：

1. 人说一句"做一支炫一点的片"，模型直接去改 `film.html`，没有分镜、没有风格、没有验收；
2. 走到一半停下来问"要不要继续"；
3. 说"做好了"，但没有抽过一帧、没有导出、没有读回输出。

这份规范把这三件事分别钉死：**闸门**（第 3 节）、**完成契约**（第 4 节）、**证据规则**（第 6 节）。

---

## 1. 何时进入生产模式

满足任一条件，**立刻**按本规范开工，不要先面试：

| 触发 | 例子 |
|---|---|
| 要做一支片 | "做一支 30 秒的产品介绍"、"把这段口播剪成短视频" |
| 要改画面或动效 | "这个镜头太呆了"、"动效再炫一点"、"加个转场" |
| 要换风格 | "换成赛博朋克"、"像苹果发布会那样" |
| 套模板 / 新建项目后的第一句需求 | 模板装好，人说"按这个做个开场" |
| 明确说继续 / 开始 | "开始吧"、"接着做" |

**不触发**（不要加载生产协议，按普通编辑处理）：

- 只问问题（"这支片多长？"、"这个按钮干什么的"）；
- 只改字幕文字、只换一个素材、只改音量；
- 明确说"先别动手 / 只给方案"。

判断不了时按"要动手"处理：先读结构、给分镜，再继续，不要停在"要不要我继续"。

## 2. 生产协议总览

```
G0 接单 → G1 分镜 → G2 定调帧 → G3 量产 → G4 声音 → G5 帧检 → G6 交付
             ↑            │
             └── 风格不对只回 G2，别回 G0
```

每一道闸门都有**产出**与**通过条件**；没通过不许进下一道。闸门之间**不停机**：
不向人确认"是否继续"，除非命中第 4 节的三种例外。

| 闸门 | 产出 | 通过条件 | 典型耗时 |
|---|---|---|---|
| G0 接单 | 一句话 brief + 三个默认值 | 知道片长、画幅、要什么情绪 | 1 分钟 |
| G1 分镜 | 分镜表（每镜：秒数 / 画面 / 动作 / 屏上字） | 总时长对得上；每镜只讲一件事 | 2–5 分钟 |
| G2 定调帧 | 只做第 1 镜；`openfilm_frame` 抽一帧 | **亲眼看过那一帧**，并说出画面里有什么 | 5–15 分钟 |
| G3 量产 | 其余镜头页面 | 每镜有入场/出场；动效来自动作库；文字不越界 | 主体工作量 |
| G4 声音 | 字幕 + 音乐/音效轨 | 字幕与镜头对齐；音乐不压旁白 | 10–20 分钟 |
| G5 帧检 | 切点前后各一帧 + 每镜中点 | 无黑场 / 静止 / 闪烁 / 空白 / 文字溢出 | 5–10 分钟 |
| G6 交付 | 成片 + 回读的输出信息 | 导出真的完成，路径与规格来自工具返回 | 5 分钟起 |

**G2 是整条协议里最便宜的一次兜底。** 风格、配色、字重、留白、动效气质都在这一帧定；
这一帧不对，后面每一镜都会重犯同一个错。所以：**G2 没通过，不许写 G3。**

## 3. 每道闸门怎么做

### G0 接单

- 先 `openfilm_film` 读结构，必要时 `openfilm_frame` 看现在长什么样；不要凭文件名猜。
- 一句话 brief 只补三个默认值：**给谁看 / 多长 / 什么情绪**。
  人没说就自己定，并在回复里用一行说明你定了什么。
- 最多问 **一个** 真正无法默认的问题。其余先做，做完再让人改。

### G1 分镜

分镜表固定四列，**一镜一行**：

| # | 秒 | 画面（屏上是什么） | 动作（怎么动） | 屏上字 |
|---|---|---|---|---|

硬规则：

1. **一镜只做一件事。** 同时发生三件事，观众一件也记不住。
2. **时长按信息量**：纯标题 1.2–2.0 s；一句话 + 一个动作 2.0–3.0 s；要读的卡 3.0–5.0 s。
3. **每个动作都要落在秒上**（"0.4 s 标题弹入，1.1 s 数字滚完"），不写"渐入""动起来"这种空话。
4. **一支片只允许一次"重音"**（推镜、闪白、冲击音效三选一），第二次就不响了。
5. 第一版不超过 **8 镜**；8 镜讲不完，是内容没收敛，不是镜头不够。

### G2 定调帧

1. 只写第 1 镜的页面（其余先留空或复用旧页）。
2. 用 `openfilm_frame` 抽 **该镜的 60% 时刻**（动作已落定、又还没出场）。
3. 看完必须回答三件事：底色/主色是什么、最大的字是什么、画面重心在哪。
4. 三件事里有一件和 brief 不符 → 改这一镜再抽，**不要**带着问题往下写。
5. 定调帧同时定下 **动作气质**：这一帧里元素是"硬切到位"还是"弹到位"，后面所有镜头跟它一致。

### G3 量产

- 动作只从 `vendor/templates/_kit/motion/` 的词汇里选（见第 5 节），不要每镜自己发明缓动。
- 每镜必须同时有 **入场** 与 **出场**（出场可以是切走，但要在时间轴上交代）。
- **静止不超过 1.2 s**：真要让人读字，就让画面极缓推近（1–2%）或加颗粒，不要完全冻住。
- 文字安全边距 ≥ 32 px（1080p）；任何一行不超过画幅宽度的 86%。
- 颜色不超过 4 个（底、面、主字、强调）；渐变要么 0 个，要么统一一个方向。
- 每写完 2–3 镜抽一次帧，不要攒到 19 镜再一起看。

### G4 声音

- 有口播：先 `openfilm_transcribe` 拿时间码，再按句子切镜（不要按字数猜）。
- 配乐：在旁白区间压到 30% 或 −12 dB；转场点不要卡在音乐半拍上。
- 音效：一个动作一个音效，不叠；全片 ≤ 6 个。
- 字幕按语义断句；每行 ≤ 18 个汉字；与切点前后 0.2 s 内对齐最佳。

### G5 帧检

按这个清单抽帧（用 `openfilm_export kind=stills` 或 `openfilm_frame`）：

1. 每个切点 **前 1 帧 / 后 1 帧**：有没有闪白、跳色、元素跳位；
2. 每镜 **中点**：是不是空白、文字有没有溢出、主体有没有被裁；
3. 片头 **0.1 s** 与片尾 **最后 0.3 s**：黑场还是正常收尾；
4. 任意两镜 **连续两帧差**：完全没变 = 静止镜头，要么是有意的 hold，要么是 bug。

发现问题就回去改对应闸门，不要"整体重做"。

### G6 交付

- 用 `openfilm_export` 导出；等 `status` 报告完成。
- **必须回读输出**：路径、分辨率、帧率、时长、文件大小。这些只能来自工具返回，不能推断。
- 回复里给：成片路径 + 规格 + 一句"哪一镜最满意 / 哪一镜还可以再改"。
- 没有文件就不叫交付。

## 4. 完成契约（什么叫"做完了"）

**做完 = 成片导出完成且回读过输出**，或人明确只要评审/方案。

### 允许停下来问的三种情况

1. 一个**无法默认**的选择（例如"这条要发给客户还是发抖音"，画幅和时长完全不同）；
2. **缺外部资源或权限**（素材不在项目里、沙箱拒绝、编码器不支持）——说清楚缺什么、怎么补；
3. **同一个失败重试两次仍不过**（渲染失败、帧检连续异常）——给出证据与下一步建议。

除这三种，**不许**用"要不要继续 / 需要我接着做吗 / 你先看看"结束一轮。
默认值、合理假设、先做后改，都是允许且被鼓励的。

### 失败处理

- 同一手段最多重试 **2 次**；第 3 次必须换手段（换工具、换实现、缩小范围）。
- 报告失败必须带：哪一步、报了什么错、已经试过什么、建议的下一步。
- 不要静默降级（比如悄悄删掉一个镜头）——改了什么要说。

### 预算

- 单镜返工 ≤ 3 次；超过就说明分镜有问题，回 G1。
- 整片返工 ≤ 2 轮；超过就先交付当前最好的一版，再谈下一轮。

## 5. 动作词汇（`_kit/motion/motion.js`）

构建时发到每个模板的 `vendor/templates/<模板>/assets/motion.js`，页面里用 `<script src="../assets/motion.js"></script>` 引入，
脚本里通过 `Motion` 或 `Scene.motion` 使用。**全部是给定 t 的纯函数**，可以乱序取帧。

| 组 | API | 说明 |
|---|---|---|
| 时间 | `seg(t,start,dur)` `stagger(i,step)` `lerp` | 进度、错峰 |
| 缓动 | `cubicOut` `quintOut` `expoOut` `inOutCubic` `backOut(p,overshoot)` | 常规曲线 |
| 弹簧 | `spring(t,duration,zeta)` | zeta 0.61 ≈ 9% 过冲（"有生命"） |
| 落体 | `drop(t,dur)` → `{y,sy,landed}` | 下坠 + 触地挤压 |
| 生长 | `wallScale(t,base,dur)` | 立面拉起 |
| 随机 | `det(frame,salt,index)` `detBetween` `halton` `jitter` | 确定性，禁 `Math.random` |
| 姿态 | `pose(el,{x,y,z,scale,rotate,rotateX,rotateY,opacity,blur})` | 合成 transform |
| 进出 | `enter(el,t,start,{spring:true})` `exit(el,t,start)` | 与旧 `Scene.enter` 默认值一致 |
| 相机 | `camera(el,{x,y,zoom,rotate})` `inversePose(pose)` | 整层推/摇/转 |
| 揭示 | `reveal(el,p,{from:'left'|'right'|'top'|'bottom'})` | clip-path 擦除 |
| 文字 | `split(el,'chars'|'words')` `unitsIn(el,t,start)` `count(el,t,{from,to})` | 逐字、滚数 |
| 画布 | `surface(canvas,{scale:2})` `grain(ctx,t,{width,height})` | 2× 超采样、确定性颗粒 |

示例（一镜里同时用到弹簧、错峰、相机）：

```js
function draw(t) {
  Motion.camera('#stage', { zoom: 1 + 0.02 * Motion.seg(t, 0, 6) });
  ['#title', '#sub', '#cta'].forEach((sel, i) => {
    Motion.enter(sel, t, 0.1 + Motion.stagger(i, 0.08), { y: 28, spring: { zeta: 0.55 } });
  });
  Motion.count('#num', t, { from: 0, to: 1280, start: 0.8, duration: 1.4, suffix: '+' });
}
```

## 7. 质量红线（出现任意一条就回炉）

1. 一整镜完全静止超过 1.2 s；
2. 全片只有一种缓动（所有东西同一个节奏）；
3. 元素从四个方向同时飞入（"PPT 动画"）；
4. 文字压主体、越界、或一屏超过 3 行；
5. 连续两个以上特效转场；
6. 配色超过 4 个主色，或出现没有来由的渐变；
7. 数字不做滚动、直接跳变；
8. 音效比画面动作晚/早 3 帧以上；
9. 字幕折行、或一行超过 18 个汉字；
10. 交付时说不出成片的分辨率、帧率、时长。

## 8. 证据规则

- **看过 = 抽过帧**。没抽帧就说"应该没问题"，等于没看。
- **导出 = 回读过输出**。只有 `openfilm_export status` 返回的路径/规格算数。
- **改动 = 说清楚**。删了镜头、换了素材、降了分辨率，都要在回复里讲。
- **不确定 = 说不确定**，并给出验证方法；不要用"大概""应该"糊过去。
